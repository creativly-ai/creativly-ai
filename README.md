## Build with Creativly

Bring image and video generation into your app, or create directly from a conversation. Keep your references and results together in Creativly projects and sessions.

| Integration | Get started |
| --- | --- |
| **[Creativly API](https://github.com/creativly-ai/creativly.ai-api)** | Generate and edit images and videos from your application. Python and JavaScript examples cover private uploads, saved jobs and original downloads. |
| **[Creativly MCP](https://github.com/creativly-ai/creativly.ai-mcp)** | Connect ChatGPT, Claude, Codex or Claude Code using OAuth. Find setup guides, the complete tool reference and briefs to try. |

The guides and examples are open source. The hosted integrations use your Creativly account and credits; available models and prices come from the live service.
